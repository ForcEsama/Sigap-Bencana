# SIGAP BENCANA — Visual Mockup Reference

Paket ini berisi hasil render visual dari dua PDF mockup untuk dipakai sebagai referensi di Codex/VS Code.

## Isi folder
- `mobile_mockup/`: gambar PNG tiap halaman mockup mobile, plus contact sheet JPG.
- `desktop_mockup/`: gambar PNG tiap halaman mockup website desktop, plus contact sheet JPG.
- Gambar individual beresolusi lebih tinggi daripada contact sheet. Gunakan contact sheet untuk inventaris halaman, lalu buka PNG individual untuk memeriksa detail layout.

## Instruksi untuk Codex
1. Baca `README.md` ini.
2. Buka dan analisis `mobile_mockup/contact_sheet_01.jpg` dan `desktop_mockup/contact_sheet_01.jpg`.
3. Jika ada lebih dari satu contact sheet, periksa semuanya.
4. Untuk setiap halaman yang akan diimplementasikan, buka PNG individual `page_XX.png` pada resolusi penuh.
5. Buat pemetaan tiap gambar ke halaman aplikasi di `docs/UI_REFERENCE.md`.
6. Jangan mengandalkan ekstraksi teks PDF saja. PNG adalah acuan visual; BRD adalah acuan kebutuhan dan aturan bisnis.
7. Jika model tidak dapat melihat gambar dari workspace, nyatakan keterbatasan itu secara eksplisit dan jangan mengaku sudah meninjaunya.
